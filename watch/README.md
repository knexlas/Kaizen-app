# Kaizen Plan for Garmin fenix 8

A Connect IQ watch app that shows your Kaizen plan and buzzes when it is time to switch.

- **Now screen:** the current block with a progress ring and time left, what's next, and today's x/y done.
  - START opens the menu.
  - DOWN opens Today.
  - UP opens Week.
- **Today / any day:** your time blocks. Each one can be marked Done, started now, or snoozed 15 min.
- **Week:** the next 7 days, plus "To schedule" (this week's tasks without a time slot). "Do today" puts one in the next free slot.
- **Projects:** open tasks per project, with what each is waiting on ("Waiting: Review copy") and what it holds up ("Blocks 2").
- **Buzz:** while the app is open, at the start and end of every block. When it is closed, a background check wakes the app at block start with "Start now: …". Garmin shows that as a prompt you confirm to open the app.

## How it syncs

```
Kaizen web app ──(signed in with Google)──► Firestore watchFeeds/{watch code} ◄──(phone)── fenix
                ◄── applies & deletes ─────  watchFeeds/{code}/events        ◄── done/snooze/start/today
```

- The web app republishes the feed whenever your plan changes.
- The watch fetches it on open, every 5 minutes while open, and at least every 30 minutes in the background.
- Actions on the watch are sent right away (queued when your phone is out of reach). **They are applied the next time Kaizen is open in a browser where you are signed in.**

## One-time setup

1. **Firestore rules:** merge `../firestore.watch.rules` into your rules in the Firebase console (Firestore Database → Rules) and publish.
2. **Kaizen:** open Settings (the gear), sign in with Google, then click **Create watch code**.
3. **Toolchain** (once per PC):
   - Java 17 or newer, e.g. `winget install EclipseAdoptium.Temurin.21.JDK`.
   - The [Connect IQ SDK Manager](https://developer.garmin.com/connect-iq/sdk/): sign in with your Garmin account, download the latest SDK, and under *Devices* download the fenix 8 models.
4. **Build** (creates `developer_key.der` the first time; keep it):

   ```powershell
   .\build.ps1 -Device fenix847mm        # or fenix843mm, fenix8solar47mm, fenix8solar51mm
   .\build.ps1 -Device fenix847mm -Run   # try it in the simulator first
   ```

   For a fenix 8 Pro, add its product id to `manifest.xml` and use it with `-Device`.
5. **Install:** connect the watch over USB and copy `bin\KaizenPlan.prg` to `GARMIN\Apps` on the watch.
6. **Enter the watch code:** Garmin Connect app → your fenix → Connect IQ apps → Kaizen Plan → Settings → *Watch code*.

## Files

| File | What it does |
| --- | --- |
| `source/KaizenApp.mc` | App entry, foreground buzz timer |
| `source/Store.mc` | Feed cache, optimistic actions, offline queue |
| `source/Sync.mc` | Firestore URLs, value decoding, reminder scheduling (shared with background) |
| `source/ReminderService.mc` | Background reminder |
| `source/NowView.mc` | Main screen |
| `source/Menus.mc` | Today / Week / Projects menus and actions |
| `source/Config.mc` | Generated by `build.ps1` from `../.env` (gitignored) |
